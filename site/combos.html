How to read this

  • legs shows which of the three a pair covers: a stranger's words, your private data, a way out.
  • A pair is only lethal when all three legs are present and the agent's context joins them.
  • This table is coarse on purpose. It finds candidates; running scan on your config runs the real path query — the expanded row below is that query's output on the committed fixture.
  • Colour is never the only signal — each leg is named in the text too.

What this table is not

  • Not a vulnerability report. A combination is not a bug in either server. Both behave as documented.
  • Not a full exploit. We describe capabilities only. We never publish payloads.
  • Not authoritative. Labels are inferred. Method is on Benchmarks.
  • Disputable. Maintainers can ask us to correct or remove an entry — see Disclosure.
