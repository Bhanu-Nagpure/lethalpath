How to read this

  • Legs shows which of the three a pair covers: a stranger’s words, your private data, a way out.
  • A pair is lethal only when all three legs are present and the agent’s context joins them. Full means the pattern has all three; partial means one is missing until you add another tool.
  • The table is coarse on purpose. It finds candidates; running scan on your config runs the real path query.
  • Colour is never the only signal — each leg is named in the text too.

What this table is not

  • Not a vulnerability report. A combination is not a bug in either server. Both behave as documented.
  • Not a full exploit. We describe capabilities only. We never publish payloads.
  • Not authoritative. Labels are inferred. Method is on Evidence.
  • Disputable. Maintainers can ask us to correct or remove an entry — see Disclosure.

Other tools, such as MSCC, also map cross-server paths. The qualitative comparison, with citations, is in docs/RELATED-WORK.md.
