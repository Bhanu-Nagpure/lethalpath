01 Detection — 40 seeded configs

Ground truth is known by construction: planted routes, laundering-only routes, clean configs, and tie cases. Each case is ingested into its own graph and scanned with the committed query.

03 Labels — a regression check, not accuracy

Labels come from a 35-row rules table (34 name rules plus one fallback) aided by tool-set expansions for 11 known servers. The gold set is 50 hand-written rows.

Label artefacts and results

gold-set rows5050/50 matchpnpm --filter @lethalpath/labeler test

We publish no precision/recall table. The gold set is self-authored alongside the rules: it proves internal consistency and catches regressions, not external ground truth. Three of the 50 rows pass by expecting the fallback resource. The rules we trust least are named in the labeler README — a missed sink makes a scan quieter; a false sink makes it noisier.

This is a demo. The guard speaks real MCP over stdio, but allowed calls return simulated results; no real GitHub, filesystem or git server sits behind it yet. The same push is blocked in a tainted session and allowed in a clean one. The guard’s own suite runs eight tests. Added latency: not measured, so no milliseconds appear here. The audit log stores tool, decision, reason and a short argument hash — never argument contents.

05 Published incidents, replayed

Four public write-ups, encoded as fixtures. Each fixture reconstructs the capabilities only — no payloads, no secrets — and carries its source and date. scan rediscovers the published chain; fix computes the revocation and re-runs the query.

Reconstructions from the write-ups, not reproductions. The Postmark incident is a malicious package, not a prompt injection; LethalPath does not detect malicious packages. The fixture shows that removing the package’s grant closes the route, which is the same fix as removing the package. Commands and limits are in docs/incident-replay.md.

06 What we did not measure

These have no number yet, so none is printed.

  • Head-to-head against other scanners — not run. The comparison is qualitative and cited in docs/RELATED-WORK.md, including where MSCC and CaMeL are ahead of us.
  • Retrieval accuracy on tool-selection datasets — not attempted. Retrieval is not the product; the path and the cut are.
  • External label ground truth — none exists yet. The 50-row gold set is self-authored, and says so.
  • Guard latency overhead — not measured. We print no milliseconds we did not time.

Reproduce any of it

# both eval suites, live — rewrites the JSON these tables read
pnpm --filter @lethalpath/eval build && pnpm --filter @lethalpath/eval evaluate

# the labeler gold run (section 03)
pnpm --filter @lethalpath/labeler test

# the guard transcript (section 04)
pnpm --filter @lethalpath/guard demo

# the committed files themselves
cat packages/eval/results/detection.json packages/eval/results/fix-quality.json
