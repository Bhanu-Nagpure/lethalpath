01 Detection — 40 seeded configs

Ground truth known by construction: planted routes, laundering-only routes, clean configs, and tie cases. Each case is ingested into its own graph and scanned with the committed query, live against FalkorDB 6.0.2 on 2026-10-17.

The honest half. A single-server trifecta check is solved work, and we publish no head-to-head table: we did not run Snyk Agent Scan, triflow or mcptrustchecker ourselves, so any comparison row would be invented. The qualitative comparison, with citations, is in docs/RELATED-WORK.md. What this table claims is narrower and reproducible: the committed query found every planted route, and all eight clean configs produced zero rows.

03 Label quality — the honest accounting

Labels come from a 35-row rules table aided by tool-set expansions for 11 known servers. The gold set is 50 hand-written rows, run in the package's own test.

gold-set rows5050/50 matchpnpm --filter @lethalpath/labeler test

We publish no precision/recall table. The gold set is self-authored alongside the rules: it proves internal consistency and catches regressions, not external ground truth. The rules we trust least are named in the labeler README — the sink end (tools named generically, like execute or process) is the weak one, which makes a scan quieter, never noisier.

The arrangement is what makes it lethal. The same push is blocked in a tainted session and allowed in a clean one. The guard's own suite runs eight tests, including the stdio end-to-end. Added latency: not measured, so no milliseconds appear here. The audit log stores tool, decision, reason and a short argument hash — never argument contents.

05 What we did not measure

A benchmarks page without this list would be a lie by omission.

  • Head-to-head against other scanners — not run. Positioning is qualitative and cited in docs/RELATED-WORK.md, including where MSCC and CaMeL are ahead of us.
  • Retrieval accuracy on tool-selection datasets — not attempted. Retrieval is not the product; the path and the cut are.
  • External label ground truth — none exists yet. The 50-row gold set is self-authored, and says so.
  • Guard latency overhead — not measured. We print no milliseconds we did not time.
